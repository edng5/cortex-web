Edward uses Spec Driven Development (SDD) in his work as Tech Lead and Machine Learning Engineer at
BMO, where he leads the move to an agentic software development lifecycle (SDLC): a clear
specification comes first, and AI coding agents build from it. Automated SDLC skills there cut
development time by up to 50%.
