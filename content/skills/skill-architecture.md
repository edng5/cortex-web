Edward designs systems end to end. As Tech Lead at BMO he leads the research, design and development
of a modernized ML architecture for automated document processing, using state-of-the-art models,
agentic AutoML, an agentic SDLC and REST API services; the upgrades doubled DocAI's throughput to
around 3 million pages a month. As Lead Software Developer he contributed to the design of the
end-to-end pipeline from file ingestion to API response, helped design microservices for automated
document processing, and migrated legacy cloud projects to a multi-account architecture. His own
projects include LeGM-CP's client-server architecture (a Next.js frontend talking to an MCP server).
