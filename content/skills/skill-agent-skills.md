Edward uses Agent Skills to have AI agents carry out real engineering work. On BMO's Apex AI
(formerly DigitalCore AI) team he automated software-development-lifecycle (SDLC) skills that cut
development time by up to 50%, as part of modernizing the team's ML architecture with agentic AutoML
and an agentic SDLC. He also built a proof of concept for an automated vulnerability-patching tool
with Agent Skills that remediated 98% of open issues.
