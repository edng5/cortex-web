## What Edward did
- Led a cross-functional team of student entrepreneurs in mobile application development,
  engineering a chatbot that lets users practice conversational skills with pronunciation and
  sentence-structure assessment in 15 languages.
- Developed and optimized a RESTful API using Node, Express, and the Azure Speech SDK by
  restructuring data pipelines, reducing process runtime from 5 minutes to less than a minute.
- Designed the front-end interface using React Native and conducted comprehensive A/B testing,
  refining UI/UX elements based on user feedback.
- Bundled the app with Expo Go and released it to the Apple App Store and Google Play Store,
  scaling to 500+ users globally.

## Tech
TypeScript, React Native, Node, Express, Expo Go, Azure Speech SDK.
